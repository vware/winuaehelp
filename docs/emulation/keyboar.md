# Keyboard

Amigas had different keyboard layouts, so WinUAE re-purposes
a couple of keys. Some to control emulation, some to emulate
keys on Amiga keyboards that other systems do not have. Below
is a description of standard mappings, but keys can be
configured freely in the [Input
Configuration](../gui/input.md).

## Shortcut Keys

| Key/Combination | Description |
| --- | --- |
| F12 | Show the WinUAE GUI |
| Shift + F12<br> End + F12 | Bring up the GUI based debugger |
| Ctrl + F12 | Switch to full-screen display |
| PrintScreen | Copy WinUAE's current screen to clipboard |
| End + PrintScreen | Save screenshot to a file |
| End + F5 | Restore a machine snapshot file |
| Shift + End + F5 | Save a machine snapshot file |
| Pause | Halt emulation |
| End + F1<br> End + F2<br> End + F3<br> End + F4 | Select an ADF to be loaded into one of the four emulated disk drives |
| Shift + End + F1<br> Shift + End + F2<br> Shift + End + F3<br> Shift + End + F4 | Eject a disk from one of the four emulated drives |
| End + J | Swap joystick ports |
| End + Insert | Insert text from host clipboard |

## Amiga Keys

| Amiga Key | Mapped To Key(s) |
| --- | --- |
| Left AMIGA | Left Windows<br> Insert |
| Right AMIGA | Right Windows<br> App Menu / Context Menu<br> Home |
| HELP | Page Down on numerical keypad |

### Action Replay

If an ActionReplay module is configured, the FREEZE button
will be mapped to Page Up on the numerical keypad

## CDTV

If the host keyboard has multimedia keys, they will be used
for their equivalent functions in CDTV emulation:

- Stop
- Pause
- Previous Track
- Next Track
